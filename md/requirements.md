# 주식 자동매매 프로그램 요구사항 정의서

## 1. 프로젝트 개요
## 1. 프로젝트 개요
- **프로젝트명**: StockAutoTrader
- **목표**: 한국투자증권(KIS) Open API를 활용하여 코스피/코스닥 종목의 자동 매매를 수행하는 파이썬 프로그램 개발
- **대상 시장**: KOSPI, KOSDAQ
- **개발 언어**: Python 3.x
- **핵심 라이브러리**: `requests` (REST API), `pandas`, `PyQt5`

## 2. 기능 요구사항

### 2.1. 접속 및 인증
- 한국투자증권 Open API (KIS) 연동
- Access Token 발급 및 갱신 관리
- 접속 상태 확인

### 2.2. 데이터 수집
- **실시간 데이터**: 장중 주가, 체결강도, 호가 정보 수신
- **과거 데이터**: 일봉/분봉 차트 데이터 조회 및 저장
- **종목 정보**: 코스피/코스닥 전 종목 코드 및 기본 정보 로딩

### 2.3. 매매 전략 (예시)
- 사용자 정의 조건식 연동 (키움증권 HTS 조건검색 활용 가능)
- 기술적 지표 활용 (이동평균선, RSI, MACD 등)
- 분할 매수/매도 로직
- 손절(Stop Loss) 및 익절(Take Profit) 자동 설정

### 2.4. 주문 실행
- 지정가/시장가 매수 및 매도 주문
- 미체결 주문 조회 및 취소/정정
- 예수금 및 보유 잔고 실시간 조회

### 2.5. 모니터링 및 알림
- 매매 체결 내역 실시간 로그 기록
- 에러 발생 시 예외 처리 및 로그 저장
- (선택 사항) 매매 체결 시 텔레그램/슬랙 알림 전송

## 3. 비기능 요구사항
- **안정성**: 장중 프로그램 중단 없이 지속 실행 (Exception Handling 필수)
- **성능**: 실시간 데이터 처리 지연 최소화 (비동기 처리 고려)
- **확장성**: 추후 다양한 매매 전략을 플러그인 형태로 추가하기 쉬운 구조

## 4. 시스템 아키텍처 (간략)
1.  **Main Controller**: 프로그램 실행 및 전체 흐름 제어
2.  **Kiwoom Interface**: Open API와 직접 통신하는 래퍼(Wrapper) 클래스
3.  **Data Manager**: 수신된 데이터 가공 및 저장 (Pandas DataFrame 활용)
4.  **Strategy Engine**: 매매 로직 판단 및 신호 생성
5.  **Order Manager**: 주문 전송 및 체결 확인

## 5. 개발 환경
- **OS**: Windows (키움증권 API 제약사항)
- **IDE**: VS Code / PyCharm
- **Version Control**: Git
